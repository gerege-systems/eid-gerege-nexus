# Байрлуулалтын бичвэр

Энэ хавтас бүрхүүлийн контейнерт `/brand` болж, зөвхөн уншигдахаар холбогдоно
(`deploy/docker-compose.yml`).

Бусдаас ӨӨР зүйл хэлдэг байрлуулалт — өөр нэр биш, өөр байр суурь — энд
`copy.json` тавьж, `BRAND_COPY_FILE=/brand/copy.json` гэж заана:

```json
{
  "website.view.hero_lede": { "mn": "…", "en": "…" },
  "website.message.footer_note": { "en": "…" }
}
```

Түлхүүрүүд нь цөмийн `frontend/lib/i18n/`-ийнх. Орлуулалт нь түлхүүр ба хэл
тус бүрээр таарна — англи бичвэр бичих нь англи хэлийг л дарж бичнэ, бусад
хэл хэвээрээ уншигдана. Орлуулалт дотор `{brand}` ажиллсаар байна.

Асахдаа нэг л удаа уншина: өөрчлөлт нь контейнер дахин асахад хүчинтэй болно —
`BRAND_NAME` шиг яг тэр мөчид.

Ихэнх суулгацад хоосон байх нь хэвийн. **Энэ суулгац дээр хоосон биш**:
`copy.json` нь нүүр хуудсыг бүхэлд нь eID Mongolia дээр эргүүлж бичдэг —
PIN1/PIN2, баталгаажуулах код, төлөөлөх эрх, итгэлцлийн гинж. Дагалдах хоёр
тохиргоо нь `.env`-д: `LANDING_SECTIONS` (аль хэсэг, ямар дараалалтай) ба
`SERVICE_URL_*` («Энэ суулгац» хэсгийн картууд).

Яагаад бичвэрээр л вэ: цөмийн бүрхүүл нь нийтэлсэн образ, энэ репо түүнийг
барьдаггүй. Хуудасны АРГУМЕНТ нь тохиргоо (`LANDING_SECTIONS`), ҮГ нь тохиргоо
(`copy.json`) — тэр хоёроор хүрэхгүй зүйл гарвал л цөмд өөрчлөлт хэрэгтэй,
энд fork хэрэгтэй биш.

Хэлний дараалал нь `copy[түлхүүр][хэл] → цөмийн overlay → цөмийн mn/en →
англи` (цөмийн `lib/i18n/index.tsx`). Тиймээс **цөмд overlay-тэй түлхүүрийг
дарахдаа долоон хэлээр бүтнээр нь бичих ёстой**: ar/es/fr/ru/zh дээр цөмийн
орчуулга нь энд бичсэн англиас ДЭЭГҮҮР ордог тул тэр таван хэл ерөнхий
платформын хуучин үг рүү чимээгүй буцна. Overlay-гүй түлхүүрт `mn` ба `en`
хангалттай — бусад хэл англи руу fallback хийнэ.

Бичвэрийн ард юу байгааг `docs/EID_MONGOLIA.md` тайлбарладаг. Тоо, нэр
өөрчлөгдвөл хоёуланг нь засна.

## Шалгах

Бүрхүүл нь хэлбэрийн алдааг асахдаа чангаар хэлдэг, харин **байхгүй түлхүүр**
болон **overlay-д дарагдсан хэл** хоёрыг хэлдэггүй — хоёул чимээгүй л
ажиллахгүй. Тиймээс цөмийн клоны хажууд нэг удаа асуу:

```bash
python3 - <<'EOF'
import json, re, pathlib
copy = json.load(open("brand/copy.json"))
core = pathlib.Path("../open-gerege-nexus/frontend/lib/i18n/addons")
loc  = pathlib.Path("../open-gerege-nexus/frontend/lib/i18n/locales")
keys = lambda p: set(re.findall(r'"(website\.[a-z_.0-9]+)"\s*:', p.read_text()))
bad = [k for k in copy if k not in keys(core / "website.ts")]
gaps = []
for l in ["ar", "es", "fr", "ru", "zh"]:
    over = keys(loc / l / "core.ts")
    gaps += [f"{k}.{l}" for k in copy if k in over and l not in copy[k]]
print("байхгүй түлхүүр:", bad or "алга")
print("overlay-д дарагдсан:", gaps or "алга")
EOF
```

CI-д ороогүй: энэ репо цөмийн frontend-ийг клонддоггүй, зөвхөн нийтэлсэн
образыг татдаг. Бичвэр засах бүрдээ гараар л ажиллуулна.
